**Java JDK(Java Development Kit)**는 자바 애플리케이션을 개발하기 위한 소프트웨어 개발 도구 모음이다. **JRE(Java Runtime Environment)**와 컴파일러(javac), 디버거, 문서 생성기 등의 개발 도구들이 포함되어 있어 자바 프로그램을 작성, 컴파일, 실행할 수 있습니다. Oracle JDK(유료)와 OpenJDK(무료) 등 여러 배포판이 있으며, 현재 LTS(Long Term Support) 버전으로는 JDK 8, 11, 17, 21이 있다. 자바 개발을 시작하려면 반드시 JDK를 설치하고 JAVA_HOME 환경 변수를 설정해야 한다.

## Windows 설치

[Oracle](https://www.oracle.com/java/technologies/downloads/)이나 [OpenJDK](https://openjdk.org/) 공식 사이트에서 Windows용 .exe 설치 파일을 다운로드합니다. 다운로드한 설치 파일을 실행하고 설치 마법사의 안내에 따라 진행하면 됩니다. 기본 설치 경로는 C:\Program Files\Java\jdk-버전 형태로 설정되며, 설치 완료 후 시스템 환경 변수에서 JAVA_HOME과 PATH를 설정해야 합다.

## macOS 설치

가장 간편한 방법은 [Homebrew](https://brew.sh/)를 사용하는 것으로, 터미널에서 **brew install openjdk@21** 명령어로 설치할 수 있습니다. 또는 Oracle이나 OpenJDK 사이트에서 macOS용 .dmg 파일을 다운로드하여 일반적인 macOS 앱 설치 방식으로 진행할 수 있다. 설치 후 터미널의 프로필 파일(.zshrc 또는 .bash_profile)에 JAVA_HOME 환경 변수를 설정해야 한다.

## 설치 이후 자바 버전 확인 및 실행

```text
# JRE 버전 확인
java -version

# JDK 컴파일러 버전 확인
javac -version

# 환경 변수 확인 (Windows)
echo %JAVA_HOME%

# 환경 변수 확인 (macOS/Linux)
echo $JAVA_HOME
```

## 간단한 자바 프로그램 실행

## 1단계: HelloWorld.java 파일 생성

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## 2단계: 컴파일 및 실행

```text
# 자바 파일 컴파일
javac HelloWorld.java

# 컴파일된 클래스 파일 실행
java HelloWorld
```

정상적으로 설치되었다면 java -version 명령어로 설치된 JDK 버전 정보가 출력되고, 간단한 Hello World 프로그램이 성공적으로 실행된다. 만약 "**java는 내부 또는 외부 명령이 아닙니다**" 등의 오류가 발생하면 환경 변수 설정을 다시 확인해야 한다.
