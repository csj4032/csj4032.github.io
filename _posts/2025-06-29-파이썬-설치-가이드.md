파이썬을 처음 배우는 분들이라면, 가장 먼저 해야 할 일이 바로 파이썬을 자신의 컴퓨터에 설치하는 것이다. 파이썬은 다양한 운영체제에서 사용할 수 있기 때문에, 본인의 환경에 맞는 방법을 선택해 설치할 수 있다. 여기서는 Windows, MacOS, 그리고 Linux에서 파이썬을 설치하는 과정을 정리했다.

## Windows에서 파이썬 설치하기

먼저, Windows 사용자는 파이썬 공식 홈페이지([https://www.python.org/downloads/)에](https://www.python.org/downloads/%29%EC%97%90) 접속해 최신 버전의 설치 파일을 다운로드한다. 다운로드가 완료되면 설치 파일을 실행하고, 설치 마법사가 안내하는 대로 진행하면 된다. 이때 주의할 점은 설치 화면에서 'Add Python to PATH'(또는 'Add python.exe to PATH') 옵션을 반드시 체크해 주는 것이다. 이 옵션을 체크해야 명령 프롬프트 어디서든 파이썬을 바로 사용할 수 있다. 설치가 완료되면, 명령 프롬프트(CMD)를 열고 다음 명령어를 입력해 파이썬 버전이 잘 출력되는지 확인한다.

```text
python --version
```

정상적으로 설치되었다면 파이썬이 준비된 것이다.

## MacOS에서 파이썬 설치하기

MacOS 사용자도 파이썬 공식 홈페이지에서 Mac용 설치 파일을 다운로드할 수 있다. 다운로드한 .pkg 파일을 더블클릭해 실행하면 설치 마법사가 안내하는 대로 '계속'을 눌러 설치를 진행하면 된다. 설치가 완료되면, 터미널을 열고 다음 명령어를 입력해 파이썬이 잘 설치되었는지 확인한다.

```text
python3 --version
```

Mac에는 기본적으로 파이썬 2.7이 설치되어 있을 수 있으니, 반드시 python3 명령어를 사용해야 최신 버전의 파이썬이 실행된다.

## Linux에서 파이썬 설치하기

Linux 사용자는 보통 이미 파이썬이 설치되어 있지만, 최신 버전이 필요하다면 직접 설치할 수 있다. 우분투 같은 배포판에서는 터미널에서 다음 명령어들을 순서대로 실행한다.

```bash
# 패키지 목록 업데이트
sudo apt-get update

# 파이썬 3 설치
sudo apt-get install python3

# pip 설치 (선택사항)
sudo apt-get install python3-pip
```

설치가 완료되면 다음 명령어로 설치된 버전을 확인할 수 있다.

```text
python3 --version
```

CentOS나 Fedora 같은 다른 배포판에서는 dnf나 yum 명령어로 비슷하게 설치할 수 있다.
